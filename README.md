# Scoot & Cafe 500 — APK Flutter

Repositori distribusi APK Android untuk staf Scoot Fitness dan Cafe 500.

## Status

Rilis Flutter pertama sedang disiapkan. Belum ada APK Flutter yang diterbitkan di repositori ini.

## Varian aplikasi

- **Gym (Scoot Kasir):** aplikasi kasir Scoot dengan Main POS sesuai akses akun.
- **Cafe (Cafe 500 Kasir):** aplikasi staf Cafe 500.

## Unduhan dan pembaruan

APK yang telah dirilis akan tersedia di [GitHub Releases](https://github.com/whyaskingme/all-in-one-scoot-app-flutter/releases).

Informasi pembaruan akan diterbitkan bersama APK yang telah diverifikasi:

- `update/gym.json` untuk varian gym.
- `update/cafe.json` untuk varian cafe.

Repositori ini berisi APK rilis, informasi versi, dan catatan pembaruan. Kode sumber aplikasi dikelola terpisah.
